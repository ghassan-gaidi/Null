full matrix → docs/threat-model.md
ADVERSARY 01

Global passive observer

Traffic analysis, timing correlation, packet sizes, social graph.

⇒ 2048-byte fixed frames · 1 frame/2s shaping + jitter · dummy cover · tor/i2p/nym

ADVERSARY 02

Active network attacker

MitM, injection, replay, rushing, message dropping.

⇒ triple-DH + ML-KEM handshake · AEAD with bound AD · transcript resync

ADVERSARY 03

Quantum (harvest now)

Ciphertexts stored today, classical keys broken tomorrow.

⇒ ML-KEM-1024 at handshake · re-encap every ≤50 msgs / 7 d · ML-DSA-65 ids

ADVERSARY 04

Local forensics

Disk imaging, swap analysis, cold boot.

⇒ zero disk writes · mlock · MADV_DONTDUMP · 3-pass panic wipe

ADVERSARY 05

Endpoint malware (user)

Keyloggers, screen capture, clipboard scrapers.

⇒ /dev/tty + evdev input · clipboard auto-clear · anti-screenshot hints

ADVERSARY 06

Nation-state censor

DPI, bridge blocking, throttling.

⇒ bridges · snowflake · webtunnel · obfs4 · latency-weighted failover

ADVERSARY 07

Coercion / seizure

Physical access, rubber-hose demands.

⇒ duress PIN · decoy mode · USBGuard panic wipe · dead-man switch

ADVERSARY 08

Supply chain

Compromised registry, substituted binaries.

⇒ pinned Cargo.lock · reproducible builds (bit-identical, CI-verified)

§5 — Run it

operator manual → docs/operations.md
null — volatile ram, bashwrite target: /dev/null
$ cargo build --locked --bin null
$ ./target/debug/null --peer loopback --tui    # self-test demo, no daemons
$ ./target/debug/null --listen 18080           # terminal 1: print your null:// string
$ NULL_DIRECT_ADDR=127.0.0.1:18080 ./target/debug/null --peer 'null://…'  # terminal 2

Over real Tor: --control-port 9051 provisions an ephemeral onion service; dial with NULL_LIVE_TRANSPORT=1. Add --verified on both sides for ML-DSA-65 mutual auth + safety number.
